# JARVIS 执行清单

这份清单按顺序走，每一步写明你要做什么、我做什么、怎么算完成。

**怎么用**：做完一项把 `[ ]` 改成 `[x]`，有「结果」行的填上数字或结论。到「你回来告诉我」那一步就停下找我，后面的交给我。

**卡住的规则**：门槛不过时先改最便宜的（描述、提示词、规则表），再改结构（合并工具、换模型），最多两轮。两轮不过就停下来一起看。
